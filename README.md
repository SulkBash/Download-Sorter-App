# FileSorterPro - Download Sorter App

FileSorterPro is a customizable file management tool that automatically sorts your downloads folder, keeping it clean and organized.

## Features

*   **Automatic Sorting:** Monitors your downloads folder and automatically moves files into designated subfolders based on their type (e.g., images, videos, documents).
*   **Customizable Rules:** (Coming Soon) Easily define your own sorting rules and folder destinations.
*   **Lightweight & Easy to Use:** Simply run the executable, and it works in the background without any complicated setup.

## Installation

1.  Download the `FileSorterPro.exe` file from the latest release.
2.  Place it in a convenient location on your computer. No installation is required.

## Usage

1.  Double-click `FileSorterPro.exe` to start the application.
2.  The app will begin monitoring your downloads folder immediately. Any new files saved to your downloads folder will be automatically sorted into the appropriate subdirectories.
